# Flexibility Allocation: Simulations

Code accompanying the paper
"Flexibility Allocation in Random Bipartite Graphs: Matching Rates and Dominance Regimes."

## Contents

`main.ipynb` contains all matching rate computations, simulations, and figure generation,
including:
- Implementation of the closed-form matching rate formulas (Corollaries 1–2)
- Hopcroft–Karp validation on random bipartite stochastic block model instances
- All figures: line plots, heatmaps, and dominance region maps

## Requirements
```
pip install numpy scipy matplotlib tqdm
```
